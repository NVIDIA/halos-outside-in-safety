### Type aliases

| Name | Definition | Description |
| --- | --- | --- |
| `SeverityLevel` | `typedef uint8_t SeverityLevel` | Fixed-width downstream event severity for PSS daemon-built `FusedSafetyEvent` entries. Client `SafetyEvent` messages do not carry severity. PSS daemon assigns one of these values when constructing `DecisionRequest` payloads for PSD/SDM routing. |
| `EventCause` | `typedef uint8_t EventCause` | Why an event was reported, orthogonal to what it reports. `type` says what happened; `EventCause` says why. Fixed width for wire stability, following the same shape as SeverityLevel and SafetyEventStatus. On the failed-sensor path, exactly one value is not diagnostic. CAUSE_SAIM_INIT marks SAIM's pre-frame fail-safe seed, which every sensor emits during startup; SDMs leave the sensor's failed bit unchanged for it, so it does not contribute to the all-safety-relevant-sensors-failed latch. **Every other value that reaches that path, including one an SDM does not recognise, is treated as a genuine failure and latches.** That asymmetry is deliberate and fails closed. CAUSE_PSS_COMM_RECOVERED is not an exception to the rule above: it rides a PSS_STATUS_NOOP, and updateSensorHealthFromDecisionRequest() skips PSS_STATUS_NOOP outright, so it never reaches the failed-sensor path at all. ADDING A VALUE IS NOT FREE, despite what an earlier version of this comment claimed. It is safe for SDM *latch* logic an unrecognised cause latches. It is NOT safe for the *validator*: validateCommonEventFields() rejects cause &gt;= CAUSE_COUNT against the RECEIVING build's bound, and a rejected `DecisionRequest` is dropped before freshness is refreshed. A peer built before the value existed therefore misses the fault the event carried and, if the condition repeats, latches on a spurious freshness timeout. Every validating runtime must be rebuilt together, which is already required for a release. CAUSE_NONE and CAUSE_SAIM_UNKNOWN are behaviourally identical both latch. They differ only in what they record: nothing set a cause, versus SAIM had a missing or contradictory one. Do not collapse them. |
