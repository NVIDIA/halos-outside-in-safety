This section documents the **Regression Testing Reporter** — the closed-loop regression-testing layer that scores Halos safety decisions against Isaac Sim ground truth. Deploy SIL first (see [SIL — 2D Perception](/testing/sil/sil-2d) for 2D or [SIL — 3D Perception](/testing/sil/sil-3d) for 3D), then use the guides below.

## Where to start

- New to the Regression Testing Reporter? Read [Overview](/testing/srr/overview).
- Ready to run a test? Go to [Quick Start Guide](/testing/srr/quickstart).
- Reading a report? See [Interpreting the Report](/testing/srr/interpret-results).
