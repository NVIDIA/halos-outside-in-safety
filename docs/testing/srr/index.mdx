This section documents the **Regression Testing Reporter** — the closed-loop regression-testing layer that scores Halos safety decisions against Isaac Sim ground truth. Deploy SIL first (see [/testing/sil/sil-2d](/testing/sil/sil-2d) for 2D or [/testing/sil/sil-3d](/testing/sil/sil-3d) for 3D), then use the guides below.

## Where to start

- New to the Regression Testing Reporter? Read [overview](/testing/srr/overview).
- Ready to run a test? Go to [quickstart](/testing/srr/quickstart).
- Reading a report? See [interpret-results](/testing/srr/interpret-results).
